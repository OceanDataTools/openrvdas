 22    def __init__(self, field_spec, interval, window,
 23                 data_id=None, metadata_interval=None, **kwargs):
 24        """
 25        ```
 26        field_spec - a dict of interpolated variables that are to be created,
 27                where the key is the new variable's name, and the value is a dict
 28                specifying the source field name and the algorithm that is to be
 29                used to do the interpolation. E.g.:
 30
 31               {
 32                 'AvgCNAVCourseTrue': {
 33                   'source': 'CNAVCourseTrue',
 34                   'algorithm': {
 35                     'type': 'boxcar_average',
 36                     'window': 30
 37                   },
 38                 },
 39                 'AvgCNAVGPSDay': {
 40                   'source': 'CNAVGPSDay',
 41                   'algorithm': { 'type': 'nearest' },
 42                 },
 43                 ...
 44               }
 45
 46               To simplify templating, can also accept a spec of the form
 47               of a list:
 48
 49               [
 50                 { sources: [MwxAirTemp, RTMPTemp, ...],
 51                   algorithm: boxcar_average,
 52                   window: 10,
 53                   result_prefix: Avg
 54                 },
 55                 { sources: [PortTrueWindDir, StbdTrueWindDir],
 56                   algorithm: polar_average,
 57                   window: 10,
 58                   result_prefix: Avg
 59                 }
 60               ]
 61
 62               Any other keys in a list entry, such as min_count, are passed
 63               to the algorithm along with its window.
 64
 65               Algorithms:
 66
 67                 boxcar_average - mean of the values within the window,
 68                       centred on the output time
 69                 polar_average - mean direction of angles (in degrees)
 70                       within the window, so that 359 and 1 average to 0
 71                 nearest - the value nearest the output time
 72                 median - median of the values within the window; unlike a
 73                       mean, unaffected by a few spikes or dropouts
 74                 trimmed_mean - mean of the values within the window after
 75                       dropping the highest and lowest; the option 'trim'
 76                       (default 0.1) is the fraction dropped from each end
 77                 time_weighted_average - mean of the values within the window,
 78                       each weighted by the time it covers (integrating
 79                       linearly between readings), so that a burst of
 80                       readings, or a gap, doesn't skew the mean as it does a
 81                       boxcar_average's. Readings are joined across a gap
 82                       left by missing values.
 83                 gaussian_average - values within the window weighted by
 84                       exp(-dt**2 / 2 sigma**2), dt being their distance from
 85                       the output time. Smoother than a boxcar, and doesn't
 86                       jump as a value enters or leaves the window. The option
 87                       'sigma' defaults to a sixth of the window, so that the
 88                       window spans 3 sigma either side
 89                 triangular_average - values within the window weighted from
 90                       1 at the output time down to 0 at the window's edges;
 91                       much like gaussian_average, and simpler
 92                 exponential_average - an exponential moving average, with
 93                       the option 'time_constant' (in seconds, required): each
 94                       new value moves the average by 1 - exp(-dt /
 95                       time_constant) of the way towards it, dt being the time
 96                       since the previous value. Unlike the other algorithms
 97                       it uses only values up to the output time, and remembers
 98                       the average from one output to the next, so its time
 99                       constant can be longer than the window. Outputs are
100                       still delayed by half the transform's window, as all
101                       outputs are, so for a live display give it a transform
102                       of its own with a short window - but no shorter than
103                       twice the interval, or values may be discarded before
104                       it sees them. No value is output once the field's
105                       latest value is more than a window old.
106
107               Window statistics, for quality control. Each is an algorithm
108               of its own, so to output several statistics of a field, list
109               it once for each, with a different result_prefix:
110                 min, max - smallest and largest value within the window.
111                       max of a short-term average gives wind gusts: the
112                       WMO gust is the maximum 3-second average, i.e. max
113                       over the output of a 3-second boxcar_average
114                 std_dev - sample standard deviation of the values within
115                       the window; needs at least two values
116                 circular_std_dev - standard deviation of angles (in
117                       degrees) within the window, by the Yamartino method,
118                       so that values either side of 0/360 are close together
119                 count - how many valid values the window holds; 0, rather
120                       than no value, when it holds none
121
122               Missing values - None, or NaN as some instruments report when
123               they have no reading - are ignored by all of them, so one
124               missing reading doesn't make a whole average NaN. If a window
125               holds nothing but missing values, no value is output for it.
126
127               Every algorithm but nearest, count and exponential_average
128               also takes an optional
129               min_count (default 1): output no value for a window that holds
130               fewer than this many valid values, rather than reporting an
131               average of one or two readings as if the window were full.
132
133               boxcar_average, median, trimmed_mean, min, max and std_dev
134               also take an optional outlier_mads: before averaging, drop values more than this many
135               median absolute deviations (MADs) from the window's median.
136               It must be at least 1, so that at least half the window is
137               always kept; 3 is a common choice. If more than half the values in a window
138               are identical, the MAD is zero and any value that differs from
139               them is dropped. min_count counts values before outliers are
140               dropped.
141
142        interval - At what intervals (in seconds) should the interpolation
143               be computed?
144
145        window - Time window (in seconds) of data we should maintain
146               around the computation we're going to make.
147
148        data_id - What data id to assign to the output
149
150        metadata_interval - how many seconds between when we attach field metadata
151               to a record we send out.
152        ```

249    def _add_record(self, record):
250        """Cached the values contained in a new record, maintaining timestamp order."""
251        if type(record) not in [DASRecord, dict]:
252            logging.error('InterpolationTransform records must be dict or '
253                          'DASRecord. Received type %s: %s', type(record), record)
254            return 0
255
256        if type(record) is DASRecord:
257            timestamp = record.timestamp
258            fields = record.fields
259        else:
260            timestamp = record.get('timestamp', 0)
261            fields = record.get('fields')
262
263        if not fields:
264            logging.info('InterpolationTransform: record has no fields: %s', record)
265            return timestamp
266
267        # First, copy the new data into our cache.  NOTE: It's a judgment
268        # call whether it's more efficient to iterate over the fields
269        # we're looking for or the fields in the record.
270        for field, new_value in fields.items():
271            if field not in self.source_fields:
272                continue
273
274            # Examine the value we've gotten. If list, we assume it's [(ts,
275            # value), (ts, value),...]
276            if type(new_value) is list:
277                for ts, val in new_value.items():
278                    self._insert_sorted(field, ts, val)
279                    logging.debug(f'adding {ts}: {field} - {val}')
280
281            # If not list, assume DASRecord or simple field dict; add tuple
282            elif timestamp:
283                self._insert_sorted(field, timestamp, new_value)
284                logging.debug(f'adding {timestamp}: {field} - {new_value}')
285            else:
286                logging.warning('Interpolation found no timestamp in '
287                                'record: %s', record)
288
289        # Update our tracking of the earliest and latest timestamps we've seen
290        self.earliest_timestamp = min(self.earliest_timestamp, timestamp)
291        self.latest_timestamp = max(self.latest_timestamp, timestamp)
292
293        # Return the timestamp of the record
294        return timestamp

297    def _insert_sorted(self, field: str, timestamp: float, value: Any) -> None:
298        """Insert a (timestamp, value) pair into the sorted cached values for a field."""
299        cache = self.cached_values[field]
300
301        # Use binary search to find insertion position to maintain sorted order
302        timestamps = [ts for ts, _ in cache]
303        pos = bisect.bisect_left(timestamps, timestamp)
304
305        # Insert at correct position to maintain sort order
306        cache.insert(pos, (timestamp, value))

309    def _clean_cache(self):
310        """Remove values from cache that are too old to be useful."""
311        for field in self.source_fields:
312            # Iterate forward through field cache until we find a timestamp
313            # that is recent enough to keep
314            cache = self.cached_values[field]
315            lower_limit = self.next_timestamp - self.window / 2
316            keep_index = 0
317            while keep_index < len(cache) and cache[keep_index][0] < lower_limit:
318                keep_index += 1
319
320            # Throw away everything before that index
321            self.cached_values[field] = cache[keep_index:]

324    def _exponential_average(self, result_field, algorithm, values, timestamp):
325        """Bring result_field's exponential moving average up to timestamp,
326        taking in the values since the latest it has taken in, and return it
327        - or None if there is no recent value."""
328        latest, average = self.exponential_averages.get(result_field, (None, None))
329        time_constant = algorithm['time_constant']
330        try:
331            for ts, val in values:
332                if ts > timestamp:
333                    break
334                if _is_missing(val) or (latest is not None and ts <= latest):
335                    continue
336                if average is None:
337                    average = val
338                else:
339                    average += (1 - exp(-(ts - latest) / time_constant)) * (val - average)
340                latest = ts
341        except TypeError:
342            logging.error('Non-numeric value in interpolation list: %s', values)
343            return None
344        self.exponential_averages[result_field] = (latest, average)
345
346        # Don't go on reporting the average of a field that has stopped
347        if latest is None or timestamp - latest > (algorithm.get('window') or self.window):
348            return None
349        return average

352    def transform(self, record: Union[DASRecord, dict]):
353        """Incorporate any useable fields in this record, and if it gives
354        us any new interpolated values, aggregate and return them as a list of
355        dicts of the form:
356
357        [
358          {'timestamp': timestamp,
359           'fields': {
360             fieldname: value,
361             fieldname: value,
362             ...
363            }
364          },
365          {'timestamp': timestamp,
366           'fields': ...
367          }
368        ]
369
370        If there are insufficient data in the window to compute any
371        interpolation, return an empty list.
372        """
373        # See if it's something we can process, and if not, try digesting
374        if not self.can_process_record(record):  # inherited from BaseModule()
375            return self.digest_record(record)  # inherited from BaseModule()
376
377        # Add the record
378        self._add_record(record)
379
380        # First time through, our 'next_timestamp' will be zero. Set it to
381        # a good starting place.
382        if not self.next_timestamp:
383            self.next_timestamp = self.earliest_timestamp
384
385        # What fields do we have data for in our cache?
386        non_empty = {}
387        for dest, spec in self.field_spec.items():
388            source = spec.get('source')
389            if source:
390                values = self.cached_values.get(source, [])
391                if len(values):
392                    non_empty[dest] = [source, len(values)]
393
394        # Iterate through all timestamps up to the edge of what we can fit
395        # in our window without running into the edge of our latest timestamp.
396        results = []
397        logging.debug(f'latest timestamp: {self.latest_timestamp}, next: {self.next_timestamp}')
398        while self.next_timestamp < self.latest_timestamp - self.window / 2:
399            # Clean out old data
400            self._clean_cache()
401
402            result = {}
403            for result_field, entry in self.field_spec.items():
404                source = entry.get('source')
405                source_values = self.cached_values.get(source)
406                algorithm = entry.get('algorithm')
407                # logging.warning('%s->%s: %d values',
408                #                source, result_field, len(source_values))
409                if algorithm.get('type') == 'exponential_average':
410                    value = self._exponential_average(result_field, algorithm,
411                                                      source_values, self.next_timestamp)
412                else:
413                    value = interpolate(algorithm, source_values,
414                                        self.next_timestamp,
415                                        self.latest_timestamp)
416                if value is not None:
417                    result[result_field] = value
418            if result:
419                result_record = {'timestamp': self.next_timestamp, 'fields': result}
420                if self.data_id:
421                    result_record['data_id'] = self.data_id
422                results.append(result_record)
423            self.next_timestamp += self.interval
424
425        return results

436def _check_algorithm_options(result_field, algorithm):
437    """Raise ValueError if an algorithm is given an option it can't use, or
438    an invalid value for one."""
439    if not isinstance(algorithm, dict):
440        return
441    alg_type = algorithm.get('type')
442
443    outlier_mads = algorithm.get('outlier_mads')
444    if outlier_mads is not None:
445        if alg_type not in OUTLIER_ALGORITHMS:
446            raise ValueError(f'InterpolationTransform: {result_field}: outlier_mads '
447                             f'can be used with {", ".join(OUTLIER_ALGORITHMS)}, '
448                             f'not {alg_type}')
449        # At least 1, so that at least half of each window is always kept:
450        # by definition, half the values are within one MAD of the median.
451        if not isinstance(outlier_mads, (int, float)) or outlier_mads < 1:
452            raise ValueError(f'InterpolationTransform: {result_field}: outlier_mads '
453                             f'must be a number no less than 1; found {outlier_mads!r}')
454
455    # count reports however many values there are, and an exponential
456    # average carries on from one output to the next: a minimum makes no
457    # sense for either
458    if alg_type in ('count', 'exponential_average') and \
459            algorithm.get('min_count') is not None:
460        raise ValueError(f'InterpolationTransform: {result_field}: min_count '
461                         f'can not be used with {alg_type}')
462
463    for option, option_alg_type in (('sigma', 'gaussian_average'),
464                                    ('time_constant', 'exponential_average')):
465        value = algorithm.get(option)
466        if value is None:
467            if option == 'time_constant' and alg_type == option_alg_type:
468                raise ValueError(f'InterpolationTransform: {result_field}: '
469                                 f'exponential_average needs a time_constant')
470            continue
471        if alg_type != option_alg_type:
472            raise ValueError(f'InterpolationTransform: {result_field}: {option} can '
473                             f'only be used with {option_alg_type}, not {alg_type}')
474        if isinstance(value, bool) or not isinstance(value, (int, float)) or value <= 0:
475            raise ValueError(f'InterpolationTransform: {result_field}: {option} must '
476                             f'be a number greater than 0; found {value!r}')
477
478    trim = algorithm.get('trim')
479    if trim is not None:
480        if alg_type != 'trimmed_mean':
481            raise ValueError(f'InterpolationTransform: {result_field}: trim can '
482                             f'only be used with trimmed_mean, not {alg_type}')
483        if not isinstance(trim, (int, float)) or not 0 <= trim < 0.5:
484            raise ValueError(f'InterpolationTransform: {result_field}: trim must '
485                             f'be at least 0 and less than 0.5; found {trim!r}')

489def _reject_outliers(vals, outlier_mads):
490    """Drop values more than outlier_mads median absolute deviations from
491    the median. If the MAD is zero, drop every value not equal to the median."""
492    center = median(vals)
493    deviations = [abs(val - center) for val in vals]
494    mad = median(deviations)
495    return [val for val, deviation in zip(vals, deviations)
496            if deviation <= outlier_mads * mad]

500def _circular_std_dev(angles):
501    """Standard deviation of angles in degrees, by the Yamartino method:
502    from how far the mean of their unit vectors falls short of length 1."""
503    val_radians = [radians(val) for val in angles]
504    sin_mean = mean([sin(val) for val in val_radians])
505    cos_mean = mean([cos(val) for val in val_radians])
506    # max() because rounding can take 1 - (length squared) just below zero
507    epsilon = sqrt(max(0.0, 1 - (sin_mean ** 2 + cos_mean ** 2)))
508    return degrees(asin(epsilon) * (1 + (2 / sqrt(3) - 1) * epsilon ** 3))

518def interpolate(algorithm, values, timestamp, now):
519    """An omnibus routine for taking a list of timestamped values, a
520    specification of an averaging algorithm, and returning a value
521    computed at the specified timestamp. Returns None if there aren't
522    enough data to compute a value.
523
524    algorithm    A dict specifying the algorithm to be used: its 'type', and
525                 options such as 'window' and 'min_count'
526
527                 Missing values (None or NaN) are ignored by every algorithm.
528
529    values       A list of [(timestamp, value),...] pairs
530
531    timestamp    The timestamp for which interpolation should be computed
532
533    now          Timestamp now. This should be used to determine whether
534                 we're far enough beyond our timestamp to compute a value.
535    """
536    if not type(algorithm) is dict:
537        logging.warning('Function interpolate() handed non-dict algorithm '
538                        'specification: %s', algorithm)
539        return None
540    # Ignore missing values: None, or NaN as some instruments send when
541    # they have no reading. Otherwise one of them would make a whole
542    # average NaN, or be returned as the nearest value.
543    values = [(ts, val) for ts, val in values if not _is_missing(val)]
544    if not values:
545        logging.debug('Function interpolate() has no values to work with')
546        # An empty window is exactly what count is there to report
547        return 0 if algorithm.get('type') == 'count' else None
548
549    ##################
550    # Select algorithm
551    alg_type = algorithm.get('type')
552    min_count = algorithm.get('min_count') or 1
553
554    # boxcar_average: all values within symmetric interval window get
555    # same weight.
556    if alg_type == 'boxcar_average':
557        window = algorithm.get('window', 10)  # How far back/forward to average
558        lower_limit = timestamp - window / 2
559        upper_limit = timestamp + window / 2
560        vals_to_average = [val for ts, val in values
561                           if ts >= lower_limit and ts <= upper_limit]
562        if len(vals_to_average) < min_count:
563            return None
564
565        try:
566            outlier_mads = algorithm.get('outlier_mads')
567            if outlier_mads:
568                vals_to_average = _reject_outliers(vals_to_average, outlier_mads)
569                if not vals_to_average:
570                    return None
571            return mean(vals_to_average)
572        except TypeError:
573            logging.error('Non-numeric value in interpolation list: %s', vals_to_average)
574            return None
575
576    # nearest: return value of nearest timestamp. Note that we assume
577    # timestamps are in order, so once distance starts going up, we're
578    # done.
579    if alg_type == 'nearest':
580        best_distance = float('inf')
581        value = None
582        for i in range(len(values)):
583            ts, ts_value = values[i]
584            distance = abs(ts - timestamp)
585            if distance <= best_distance:
586                best_distance = distance
587                value = ts_value
588            else:
589                break
590        return value
591
592    # polar_average: interpret as an angle in degrees. Convert to points
593    # on a unit circle and return the angle of their centroid from the origin.
594    if alg_type == 'polar_average':
595        window = algorithm.get('window', 10)  # How far back/forward to average
596        lower_limit = timestamp - window / 2
597        upper_limit = timestamp + window / 2
598        vals_to_average = [val for ts, val in values
599                           if ts >= lower_limit and ts <= upper_limit]
600        if len(vals_to_average) < min_count:
601            return None
602
603        try:
604            val_radians = [radians(val) for val in vals_to_average]
605            x_mean = mean([sin(val) for val in val_radians])
606            y_mean = mean([cos(val) for val in val_radians])
607            angle = degrees(atan2(x_mean, y_mean))
608            if angle < 0:
609                angle += 360
610            # A tiny negative angle (rounding error when angles cancel
611            # around north) plus 360 rounds to exactly 360.0
612            if angle >= 360:
613                angle -= 360
614            return angle
615        except (TypeError, ValueError):  # ValueError: sin() or cos() of inf
616            logging.error('Non-numeric or infinite value in interpolation list: %s',
617                          vals_to_average)
618            return None
619
620    # median and trimmed_mean: robust to a few spikes or dropouts.
621    if alg_type in ('median', 'trimmed_mean'):
622        window = algorithm.get('window', 10)  # How far back/forward to look
623        lower_limit = timestamp - window / 2
624        upper_limit = timestamp + window / 2
625        vals_to_average = [val for ts, val in values
626                           if ts >= lower_limit and ts <= upper_limit]
627        if len(vals_to_average) < min_count:
628            return None
629
630        try:
631            outlier_mads = algorithm.get('outlier_mads')
632            if outlier_mads:
633                vals_to_average = _reject_outliers(vals_to_average, outlier_mads)
634                if not vals_to_average:
635                    return None
636            if alg_type == 'median':
637                return median(vals_to_average)
638
639            vals_to_average = sorted(vals_to_average)
640            drop = int(len(vals_to_average) * algorithm.get('trim', 0.1))
641            if drop:
642                vals_to_average = vals_to_average[drop:-drop]
643            return mean(vals_to_average)
644        except TypeError:
645            logging.error('Non-numeric value in interpolation list: %s', vals_to_average)
646            return None
647
648    # time_weighted_average: integrate linearly between readings (the
649    # trapezoidal rule) and divide by the time they span, so each value
650    # counts for the time it covers rather than once.
651    if alg_type == 'time_weighted_average':
652        window = algorithm.get('window', 10)  # How far back/forward to average
653        lower_limit = timestamp - window / 2
654        upper_limit = timestamp + window / 2
655        in_window = [(ts, val) for ts, val in values
656                     if ts >= lower_limit and ts <= upper_limit]
657        if len(in_window) < min_count:
658            return None
659
660        try:
661            span = in_window[-1][0] - in_window[0][0]
662            if not span:  # all at one time, so no time to weight them by
663                return mean([val for ts, val in in_window])
664            area = sum((ts_1 - ts_0) * (val_0 + val_1) / 2
665                       for (ts_0, val_0), (ts_1, val_1) in zip(in_window, in_window[1:]))
666            return area / span
667        except TypeError:
668            logging.error('Non-numeric value in interpolation list: %s', in_window)
669            return None
670
671    # gaussian_average and triangular_average: weight values by their
672    # distance from the output time.
673    if alg_type in ('gaussian_average', 'triangular_average'):
674        window = algorithm.get('window', 10)  # How far back/forward to average
675        lower_limit = timestamp - window / 2
676        upper_limit = timestamp + window / 2
677        in_window = [(ts, val) for ts, val in values
678                     if ts >= lower_limit and ts <= upper_limit]
679        if len(in_window) < min_count:
680            return None
681
682        if alg_type == 'gaussian_average':
683            sigma = algorithm.get('sigma') or window / 6
684            weights = [exp(-(ts - timestamp) ** 2 / (2 * sigma ** 2))
685                       for ts, val in in_window]
686        else:
687            weights = [1 - abs(ts - timestamp) / (window / 2) for ts, val in in_window]
688        total_weight = sum(weights)
689        if not total_weight:  # e.g. a triangle's only values at its very edges
690            return None
691        try:
692            return sum(weight * val for weight, (ts, val)
693                       in zip(weights, in_window)) / total_weight
694        except TypeError:
695            logging.error('Non-numeric value in interpolation list: %s', in_window)
696            return None
697
698    # Window statistics, for quality control
699    if alg_type in WINDOW_STATISTICS:
700        window = algorithm.get('window', 10)  # How far back/forward to look
701        lower_limit = timestamp - window / 2
702        upper_limit = timestamp + window / 2
703        vals_in_window = [val for ts, val in values
704                          if ts >= lower_limit and ts <= upper_limit]
705        if alg_type == 'count':
706            return len(vals_in_window)
707        if len(vals_in_window) < min_count:
708            return None
709
710        try:
711            outlier_mads = algorithm.get('outlier_mads')
712            if outlier_mads:
713                vals_in_window = _reject_outliers(vals_in_window, outlier_mads)
714                if not vals_in_window:
715                    return None
716            if alg_type == 'min':
717                return min(vals_in_window)
718            if alg_type == 'max':
719                return max(vals_in_window)
720            if alg_type == 'std_dev':
721                return stdev(vals_in_window) if len(vals_in_window) > 1 else None
722            return _circular_std_dev(vals_in_window)
723        except (TypeError, ValueError):  # ValueError: sin() or cos() of inf
724            logging.error('Non-numeric or infinite value in interpolation list: %s',
725                          vals_in_window)
726            return None
727
728    # Not an algorithm we recognize
729    else:
730        logging.warning('Function interpolate() received unrecognized algorithm '
731                        'type: %s', alg_type)
732        return None

         boxcar_average - mean of the values within the window,
               centred on the output time
         polar_average - mean direction of angles (in degrees)
               within the window, so that 359 and 1 average to 0
         nearest - the value nearest the output time
         median - median of the values within the window; unlike a
               mean, unaffected by a few spikes or dropouts
         trimmed_mean - mean of the values within the window after
               dropping the highest and lowest; the option 'trim'
               (default 0.1) is the fraction dropped from each end
         time_weighted_average - mean of the values within the window,
               each weighted by the time it covers (integrating
               linearly between readings), so that a burst of
               readings, or a gap, doesn't skew the mean as it does a
               boxcar_average's. Readings are joined across a gap
               left by missing values.
         gaussian_average - values within the window weighted by
               exp(-dt**2 / 2 sigma**2), dt being their distance from
               the output time. Smoother than a boxcar, and doesn't
               jump as a value enters or leaves the window. The option
               'sigma' defaults to a sixth of the window, so that the
               window spans 3 sigma either side
         triangular_average - values within the window weighted from
               1 at the output time down to 0 at the window's edges;
               much like gaussian_average, and simpler
         exponential_average - an exponential moving average, with
               the option 'time_constant' (in seconds, required): each
               new value moves the average by 1 - exp(-dt /
               time_constant) of the way towards it, dt being the time
               since the previous value. Unlike the other algorithms
